# opencode-dotnet

Unofficial .NET tooling for [opencode](https://opencode.ai).
These projects are not built by, affiliated with, or endorsed by the opencode team.

| Project | Purpose |
|---|---|
| [opencode-sdk-dotnet](https://github.com/opencode-dotnet/opencode-sdk-dotnet) | Strongly typed .NET client for the opencode server's HTTP API. NuGet: [OpenCodeDotNet.Sdk](https://www.nuget.org/packages/OpenCodeDotNet.Sdk). |
| [opencode-mcp](https://github.com/opencode-dotnet/opencode-mcp) | Model Context Protocol (MCP) server project for opencode. |
| [opencode-agents-ai](https://github.com/opencode-dotnet/opencode-agents-ai) | Microsoft Agent Framework provider project for opencode. |

Start with the SDK's [README](https://github.com/opencode-dotnet/opencode-sdk-dotnet/blob/master/README.md)
or follow the [QuickStart sample](https://github.com/opencode-dotnet/opencode-sdk-dotnet/tree/master/playground/quickstart).

Use the relevant project's repository for questions and bug reports.
